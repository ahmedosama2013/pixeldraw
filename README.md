## 🎨 PixelDraw

PixelDraw is a clean, modern pixel art creation web application built to help you design retro artwork, experiment with color palettes, and export high-resolution assets effortlessly.

## ✨ Features

* **Versatile Drawing Tools:** Easily switch between pencil, eraser, and bucket fill tools for quick creation.
* **Flexible Grid Sizes:** Choose from multiple grid resolutions ranging from 16x16 up to 100x100.
* **Custom Colors & Presets:** Pick any custom color using the native color picker or use quick-access preset palettes.
* **Advanced Export Options:** Export your artwork as PNG (transparent/lossless), JPG, or scalable SVG with customizable scale multipliers (up to 16x).
* **Auto-Save & Privacy:** All artwork is saved directly in your browser or device local storage so you never lose progress.
* **Responsive Web App:** Optimized for both desktop and mobile screens.
